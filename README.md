# Description
This is an implementation of the game snake, which runs in the terminal. I made it to test out Ada and to see how Ada interfaced with C.

# Dependencies
You will need gcc-ada to compile this project.

# Usage
Once you are inside the project directory, you can compile the project by executing the following:
```
$ gnatmake main
```
And you can run the project by executing the following:
```
$ ./main
```
